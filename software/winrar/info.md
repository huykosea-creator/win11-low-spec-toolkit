# WinRAR (.rar) - Trình nén & giải nén phổ biến nhất

- **Mục đích:** Nén và giải nén chuẩn `.rar`, `.zip`, `.7z`, `.iso` và nhiều định dạng lưu trữ khác.
- **Trang chủ:** https://www.win-rar.com/
- **Link tải chính thức:** [WinRAR Official Download](https://www.rarlab.com/download.htm)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install RARLab.WinRAR
  ```

> 💡 *Bạn có thể tải sẵn file `winrar-x64.exe` và lưu trữ trực tiếp vào thư mục này để cài đặt offline.*
