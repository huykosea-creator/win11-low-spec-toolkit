# VLC Media Player - Trình phát đa phương tiện toàn năng

- **Mục đích:** Phát mọi định dạng video, âm thanh (MP4, MKV, AVI, MP3, FLAC...), xem đĩa DVD/VCD, stream mạng không cần cài thêm bộ codec rời.
- **Mã nguồn mở:** 100% miễn phí, không quảng cáo, không theo dõi người dùng.
- **Trang chủ:** https://www.videolan.org/vlc/
- **Link tải:** [VLC Official Download](https://www.videolan.org/vlc/download-windows.html)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install VideoLAN.VLC
  ```
