# UniKey - Bộ gõ tiếng Việt tiêu chuẩn

- **Mục đích:** Gõ tiếng Việt theo chuẩn Telex, VNI. Gọn nhẹ, quen thuộc và tương thích tốt.
- **Tác giả:** Phạm Kim Long
- **Trang chủ chính thức duy nhất:** https://www.unikey.vn/
- **Link tải bản mới nhất:** [UniKey Official Download](https://www.unikey.vn/vietnam/#nav-download)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install UniKey.UniKey
  ```

> ⚠️ *Lưu ý quan trọng:* Chỉ tải UniKey từ trang chủ `unikey.vn`, tránh các trang giả mạo chứa virus. Bạn có thể lưu trữ file `UniKeyNT.exe` trực tiếp vào thư mục này.
