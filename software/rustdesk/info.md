# RustDesk - Phần mềm Remote Desktop mã nguồn mở hiện đại

- **Mục đích:** Điều khiển máy tính từ xa thay thế TeamViewer/AnyDesk. Mã nguồn mở, bảo mật cao, hỗ trợ tự dựng Server riêng (Self-hosted).
- **Trang chủ:** https://rustdesk.com/
- **Link tải mới nhất (GitHub):** [RustDesk Releases](https://github.com/rustdesk/rustdesk/releases)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install RustDesk.RustDesk
  ```

> 💡 *Không cần cài đặt vẫn có thể chạy trực tiếp dạng Portable.*
