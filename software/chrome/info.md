# Google Chrome - Trình duyệt web hàng đầu

- **Mục đích:** Lướt web tốc độ cao, đồng bộ tài khoản Google, kho tiện ích mở rộng (Extensions) phong phú.
- **Trang chủ:** https://www.google.com/chrome/
- **Link tải:** [Google Chrome Download](https://www.google.com/chrome/)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install Google.Chrome
  ```

> 💡 *Mẹo cho máy ít RAM:* Vào Cài đặt Chrome -> **Hiệu suất (Performance)** -> Bật tính năng **Bộ tiết kiệm bộ nhớ (Memory Saver)** để tự động giải phóng RAM các tab không hoạt động.
