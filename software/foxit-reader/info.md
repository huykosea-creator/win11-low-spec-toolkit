# Foxit PDF Reader

- **Tên:** Foxit PDF Reader
- **Nhà phát triển:** Foxit Software Inc.
- **Trang chủ:** https://www.foxit.com/pdf-reader/
- **Winget Package ID:** `Foxit.FoxitReader`
- **Mục đích:** Xem, chú thích, in ấn và ký tài liệu PDF chuyên nghiệp, đầy đủ tính năng.
- **Dung lượng RAM:** Vừa phải (~60MB - 120MB).
- **Lệnh cài đặt trực tiếp:**
  ```cmd
  winget install --id Foxit.FoxitReader --exact --accept-package-agreements --accept-source-agreements
  ```
