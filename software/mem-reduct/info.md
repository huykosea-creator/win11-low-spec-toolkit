# Mem Reduct - Công cụ giải phóng RAM tức thì

- **Mục đích:** Giám sát và dọn dẹp bộ nhớ RAM (System Working Set, Standby List, Modified Page List). Cực kỳ hữu dụng cho máy có 2GB - 4GB RAM.
- **Mức ăn RAM:** ~3MB (chạy nền gần như vô hình).
- **Tính năng hay:** Có thể thiết lập tự động dọn RAM khi dung lượng dùng vượt quá 80% hoặc sau mỗi 15 phút.
- **Trang chủ:** https://www.henrypp.org/product/memreduct
- **Link tải (GitHub Releases):** [Mem Reduct Releases](https://github.com/henrypp/memreduct/releases)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install "Henry++ .MemReduct"
  ```
