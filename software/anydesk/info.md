# AnyDesk - Phần mềm kết nối từ xa tốc độ cao

- **Mục đích:** Truy cập và điều khiển máy tính từ xa siêu mượt nhờ codec nén DeskRT độc quyền, dung lượng cài đặt cực nhẹ (~5MB).
- **Trang chủ:** https://anydesk.com/
- **Link tải:** [AnyDesk Official Download](https://anydesk.com/en/downloads/windows)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install AnyDeskSoftwareGmbH.AnyDesk
  ```

> 💡 *File `AnyDesk.exe` có thể chạy trực tiếp ngay không cần cài đặt cố định vào ổ C.*
