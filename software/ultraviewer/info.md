# UltraViewer - Phần mềm điều khiển máy tính từ xa

- **Mục đích:** Hỗ trợ từ xa, điều khiển máy tính qua mạng, chat và truyền file tiện lợi, phổ biến tại Việt Nam.
- **Trang chủ:** https://www.ultraviewer.net/
- **Link tải:** [UltraViewer Official Download](https://www.ultraviewer.net/vi/download.html)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install UltraViewer.UltraViewer
  ```

> 💡 *Bạn có thể tải file `UltraViewer_setup.exe` lưu trực tiếp tại thư mục này.*
