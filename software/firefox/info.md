# Mozilla Firefox - Trình duyệt mã nguồn mở bảo mật & riêng tư

- **Mục đích:** Lướt web tự do, bảo vệ quyền riêng tư mạnh mẽ, nhân Gecko độc lập không phụ thuộc Chromium.
- **Trang chủ:** https://www.mozilla.org/firefox/
- **Link tải:** [Firefox Official Download](https://www.mozilla.org/firefox/new/)
- **Lệnh cài đặt tự động (Winget):**
  ```powershell
  winget install Mozilla.Firefox
  ```
